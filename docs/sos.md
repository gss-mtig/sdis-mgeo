# SOS: servicios clásicos de observación de sensores

**Sensor Observation Service (SOS)** es una interfaz OGC clásica para acceder a observaciones de sensores. Una observación vincula un resultado medido con una propiedad observada, un procedimiento de medición, un momento y una ubicación o entidad de interés.

SOS puede aparecer en infraestructuras existentes, en especial cuando se publican redes de sensores y series de observaciones. Para interpretar sus resultados también hay que entender el modelo de observaciones empleado.

**SensorThings API** es una API OGC moderna para conectar dispositivos y acceder a datos de sensores y observaciones. Tiene un modelo propio: conviene entenderla como una alternativa actual relacionada, no como una versión nueva de SOS.

En esta asignatura SOS se presenta como panorama. Consulta el [panorama de otros estándares](otros.md) y la [página oficial de SensorThings API](https://www.ogc.org/standards/sensorthings/).
