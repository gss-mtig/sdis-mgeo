# GML: un formato geográfico basado en XML

**Geography Markup Language (GML)** es un formato de OGC para codificar entidades geográficas y sus propiedades en XML. Puede transportar geometrías, atributos y referencias a sistemas de coordenadas. Es un formato de datos, no un servicio web.

GML aparece en servicios clásicos, por ejemplo como formato de respuesta de algunas implementaciones WFS. Puede expresar modelos complejos, aunque sus documentos suelen ser más verbosos que otros formatos usados en la Web.

En OGC API – Features es frecuente encontrar respuestas en GeoJSON además de HTML. Para comparar las estructuras, revisa [OGC API – Features](ogc_api_features.md) y la lección de [GeoJSON](geojson.md).

Fuente: [estándar GML de OGC](https://www.ogc.org/standards/gml/).
