# CSW: búsqueda clásica de metadatos

**Catalogue Service for the Web (CSW)** es un estándar OGC clásico para buscar y recuperar registros de catálogos, incluidos metadatos geográficos. Su interfaz define operaciones para consultar capacidades, buscar registros y recuperar una ficha por su identificador.

CSW permite que una aplicación busque registros en catálogos que implementan la interfaz. En las IDE actuales también pueden encontrarse catálogos con interfaces web y API más recientes.

[OGC API – Records](https://ogcapi.ogc.org/records/) ofrece patrones web modernos para descubrir y consultar registros de metadatos. La lección de [catálogos de metadatos](catalogo_metadatos.md) explica la tarea que resuelven; aquí basta con reconocer CSW como el protocolo clásico.

Fuentes: [estándar CSW de OGC](https://www.ogc.org/standards/cat/) y [OGC API – Records](https://ogcapi.ogc.org/records/).
