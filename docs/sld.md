# SLD: estilos para representar mapas

**Styled Layer Descriptor (SLD)** es una especificación de OGC para describir estilos cartográficos en XML. Un estilo define cómo dibujar elementos geográficos —por ejemplo, el color de una línea o el relleno de un polígono—.

Algunos servidores WMS admiten estilos definidos por el usuario mediante SLD. La compatibilidad depende del servidor y de su configuración; no debe darse por supuesta. SLD modifica la representación del mapa, no los datos ni la forma de descargarlos.

La lección de [WMS](wms.md) explica cómo el estilo interviene en una solicitud de mapa. En este curso SLD queda como un estándar de referencia, no como una práctica principal.

Fuente: [estándar SLD de OGC](https://www.ogc.org/standards/sld/).
