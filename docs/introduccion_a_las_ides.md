# Qué es una Infraestructura de Datos Espaciales

La información geográfica describe fenómenos relacionados con un lugar: dónde están los ríos, qué zonas tienen más población o cómo se distribuye el transporte público. La producen organizaciones distintas y puede publicarse en formatos, páginas y sistemas diferentes.

Por eso estos datos no siempre se encuentran con una búsqueda web corriente: pueden estar repartidos entre organismos y geoportales, descritos con términos distintos o publicados sin una ficha que explique su contenido, fecha, cobertura y condiciones de uso. Antes de que se coordinaran estos recursos, cada organismo podía producir y gestionar sus datos por separado.

A otras organizaciones les costaba saber qué existía, quién lo mantenía y cómo obtenerlo o combinarlo; además, podían repetir trabajos y volver a producir datos que ya existían. Las IDE surgieron para resolver estos problemas mediante acuerdos, descripciones y servicios comunes que ayudan a descubrir, entender, compartir y reutilizar la información geográfica entre organizaciones.

El concepto de IDE se desarrolló durante la década de 1990; un hito fue la iniciativa estadounidense de Infraestructura Nacional de Datos Espaciales, formalizada en **1994**. En España, la primera iniciativa de este tipo fue la **Infraestructura de Datos Espaciales de Cataluña (IDEC)**: se presentó en 2001 y comenzó su desarrollo y catalogación en 2002. La IDEE empezó a publicar servicios y recursos en 2004.

Por tanto, las IDE son anteriores a la expansión de los portales y políticas de datos abiertos de finales de los años 2000: nacieron para organizar el acceso y el intercambio de información geográfica, con independencia de que cada recurso tuviera condiciones de acceso abiertas o restringidas. ([FGDC: iniciativa NSDI de 1994](https://www.fgdc.gov/nsdi/policyandplanning/executive_order); [IDEC: qué es la IDEC](https://www.ide.cat/es/La-IDEC/Que-es-la-IDEC); [IDEE: iniciativa pionera de Cataluña](https://www.idee.es/resources/documentos/SegINSPIRE/100720_Report_INSPIRE_2009_Spain_v2.pdf); [IDEE: 20 años de la IDEE](https://blog.idee.es/web/guest/archivo/-/blogs/conferencia-20-anos-de-la-infraestructura-de-datos-espaciales-de-espana-idee-?_com_liferay_blogs_web_portlet_BlogsPortlet_showOnlyIcons=true&scroll=_com_liferay_blogs_web_portlet_BlogsPortlet_discussionContainer))

Una **Infraestructura de Datos Espaciales (IDE)** es una red organizada de personas, organizaciones, datos, descripciones, servicios, herramientas y acuerdos que permite descubrir, entender, compartir y utilizar esa información geográfica.

Una IDE no es solamente un mapa web ni un programa de Sistemas de Información Geográfica (SIG). Un SIG permite trabajar con información geográfica; una IDE conecta los recursos, los productores y los usuarios para que se puedan encontrar y utilizar.

## Los componentes de una IDE

1. **Datos geográficos.** Representan lugares o fenómenos: ríos, municipios, edificios, parcelas, espacios naturales o zonas inundables. Pueden ser puntos, líneas, áreas, imágenes y otros tipos de información.
2. **Metadatos.** Describen los datos o servicios: quién los produce, qué representan, qué zona cubren, cuándo se crearon o revisaron y bajo qué condiciones se pueden usar.
3. **Catálogo.** Permite buscar las fichas que describen los datos y servicios disponibles. No necesariamente almacena los datos.
4. **Servicios y descargas.** Un visor permite explorar un mapa; una descarga entrega una copia de datos; un servicio web permite que otras aplicaciones soliciten información.
5. **Aplicaciones cliente.** Son herramientas para consultar o combinar recursos, como un navegador, un visor web o un SIG como QGIS.
6. **Personas, acuerdos y reglas comunes.** Las organizaciones definen quién mantiene la información, cómo se describe y cómo facilitar que distintos sistemas la compartan.

Cuando estos componentes se coordinan, se facilita la **interoperabilidad**: la posibilidad de compartir y combinar recursos entre organizaciones y aplicaciones con menos adaptaciones manuales.

## Una comparación para entenderlo

Piensa en una biblioteca. Su catálogo ayuda a localizar un libro y conocer su autor, tema y edición, pero no es el libro. De forma parecida, un catálogo geográfico permite encontrar una ficha que describe un recurso y enlaza a las formas de acceder a él.

| En una biblioteca                | En una IDE                                         |
| -------------------------------- | -------------------------------------------------- |
| Libro                            | Conjunto de datos geográficos                      |
| Ficha del catálogo               | Metadatos del dato o servicio                      |
| Catálogo de la biblioteca        | Catálogo geográfico                                |
| Consulta o préstamo              | Visor, servicio web o descarga                     |
| Biblioteca, editorial y lectores | Organizaciones productoras, proveedoras y usuarias |

La comparación tiene un límite: un recurso geográfico puede estar alojado y actualizado por un organismo, descrito en un catálogo mantenido por otro y utilizado desde una aplicación distinta.
