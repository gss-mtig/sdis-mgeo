# WMTS: mapas en teselas

**Web Map Tile Service (WMTS)** sirve mapas como teselas asociadas a una cuadrícula y a niveles de escala predefinidos. Las teselas preparadas permiten mostrar mapas con rapidez, aunque limitan la extensión, las escalas y la personalización frente a una petición de mapa dinámica.

En términos sencillos, **WMS** dibuja una imagen para cada solicitud; **WMTS** ofrece teselas previamente organizadas. Ambos pueden combinarse en una aplicación, según las necesidades y capacidades del servicio.

[OGC API – Tiles](https://ogcapi.ogc.org/tiles/) es la evolución moderna para publicar teselas mediante recursos web. Está diseñado para admitir mapas, teselas vectoriales y otros tipos de información teselada. Consulta también el [panorama de estándares](otros.md).

Fuente: [estándar WMTS de OGC](https://www.ogc.org/standards/wmts/).
